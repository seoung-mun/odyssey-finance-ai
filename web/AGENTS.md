# web — React 규칙

루트 `AGENTS.md`를 상속한다. 제품 흐름은 `../docs/기획서.md`, 데이터 계약은
`../API/openapi-public.yaml`이 기준이다. 스택은 React 18, Vite, TypeScript다.

## 구현 순서

장식보다 로그인/데모 진입 → 프로필 → 목표 → 계획 비교 → fan chart·설명 → 재계획 이력을
수직으로 완성한다. API에 없는 필드나 상태를 가정하지 않는다.

- 모든 API 화면은 `loading`, `empty`, `error`, 성공을 구분한다.
- LLM `FALLBACK`을 계산 실패처럼 표시하지 않는다.
- 금액·퍼센트·날짜 의미를 임의로 바꾸지 않는다.
- 중복 제출과 늦게 도착한 이전 응답을 처리한다.
- mock은 명시된 개발 fixture로만 쓰고 완료된 경로에 남기지 않는다.

별도 시안이 없으면 정보 구조와 시각 방향은 Web 에이전트가 정한다. 실제 필요 전에는 디자인
시스템, 전역 상태 관리, 차트 의존성을 추가하지 않는다. 모바일, 키보드 조작, 색상 외 상태
표현을 기본으로 지킨다.

## 소유권과 검증

Web 에이전트는 `web/`만 수정한다. `API/`, `docs/`, `TODO.md`와 다른 서비스 변경은
메인에게 반환한다.

```bash
npm run lint
npm run build
```

화면 변경은 실제 브라우저로 확인한다. 적대적 QA는 느린 응답, 빈 데이터, 4xx·5xx,
깨진 응답, 연속 클릭, 모바일 폭, 키보드 탐색과 LLM fallback을 확인한다.
