# 코드 읽는 법

## Fast API

1. `montecarlo.py`

- 몬테카를로 시뮬레이션 구현 파일
- `simulate` : 과거 월별 지출을 무작위로 다시 뽑고, 절감률을 적용하여 월별 순현금흐름 누적 계산
- 과거의 이력을 바탕으로 미래 N개월의 소비를 가상으로 여러 번 생성하고, 절감 계획을 적용했을 때의 누적 잔액 범위를 계산한다.

[AI 활용]

$$
R_{p,t,c} =
\begin{cases}
S_{p,t,c}(1-r) & \text{변동지출} \\
S_{p,t,c} & \text{고정지출}
\end{cases}
$$


2. `planning.py`

- `compute_presets`, `compute_custom` 이 두 함수를 위주로 리뷰

```
공통 흐름
입력 payload
  ├─ _resolve_spending_floor(): 소비 하한 확정
  ├─ _sample_paths(): 과거 지출로 미래 시나리오 생성
  ├─ _coverage(): 예산 충족 확률 계산
  ├─ _option(): 화면용 옵션 요약 생성
  └─ _bands(): 월별 누적저축 p10~p90 생성
```

- `canonical_hash` : 입력 JSON 정렬 후, 해시화 -> 같은 입력이면 같은 해시를 사용하여 결과 추적 가능
- `_camel_case`, `_camel_case_key` : random_seed(python) -> randomSeed(API)
- `_normalized_snapshot` : input_snapshot 만 입력
- `_calendar_ratio` : 비율 보정 함수
- `_sample_paths` : 과거 월별 변동 지출을 n_paths * horizon_months 만큼 무작위로 뽑아 미래 지출 시나리오 제작
- `_round_fraction` : 반올림 함수
- `_linear_quantile` : 분위수 위치를 정확한 분수로 계산
- `_quantile_money` : 분위수를 실제 원 단위 금액으로 계산
- `_coverage` : 예산을 충족하는 시나리오 비율 계산
- `_resolve_spending_floor` : 모드에 따른 하한과 절감률 변환
- `_option` : 과거 지출 중 최근 2년 결과만 가져와서 목표 절감액 달성한 날 비율 계산, 권장 소비액이 현실적인지, 얼마나 줄여야하는지 계산 및 조립
- `_bands` : 옵션 하나에 대해 월별 누적 저축의 분위수 계산
- `_simulation` : 전체적으로 메타데이터로 묶기


- `compute_presets`
    - `preset_levels` 의 각 목표 확률에 맞는 권장 월 소비액과 밴드 계산

-  `compute_custom` : 사용자가 정한 값을 기준으로 계산
